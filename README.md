## Team Agreements

- **Navigation Area**:  
  Every page in the site must include the same navigation bar, linking to all major pages (Home, About, Projects, Contact, etc.).

- **Stylesheet**:  
  All pages must use the same shared stylesheet (`style.css`) to ensure consistent design and formatting across the site.
